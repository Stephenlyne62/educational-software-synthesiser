# Goal-Oriented Educational Software Synthesiser

This repository contains the software artefact developed for the MSc dissertation:

**Design, Implementation and Evaluation of a Goal-Oriented Educational Software Synthesizer Interface for Novice Users**

The project contains two software synthesiser interfaces developed in C++ using the JUCE framework:

- Version A: conventional parameter-centric interface
- Version B: goal-oriented educational interface

Both interfaces use a shared digital signal processing engine to maintain functional equivalence.

## Development Environment

- C++
- JUCE framework
- Microsoft Visual Studio
- Windows

## Main Features

- Two oscillators
- Resonant low-pass filter
- ADSR envelope
- LFO modulation
- Preset management
- Semantic educational controls
- Contextual guidance
- Visual feedback
- “What Changed?” technical explanation panel
